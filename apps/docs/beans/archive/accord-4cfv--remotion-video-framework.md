## Summary of Changes

- New workspace package `apps/remotion` (`@useaccord/remotion`, Remotion 4.0.513, webpack bundler).
- `defineVideo` contract + `videos/<slug>/` convention; CLI (`sync`/`new`) regenerates the gitignored `src/videos.gen.ts` manifest on every script command. Tracked: `videos/_example` (reference video) + `videos/_template` (scaffold); all other videos gitignored.
- ui-kit obedience: `src/shell/theme.css` mirrors the app Tailwind v4 wiring; `<Stage>` gates rendering on `document.fonts.ready`; `EASE_EXPO`/`SPRING` presets mirror the kit's brand motion. Critical discovery: Remotion's webpack CSS chain has NO PostCSS stage — `remotion.config.ts` appends `postcss-loader` to the CSS rule (right-to-left loader order) and `postcss.config.js` must be `.js` (not `.mjs`) or it is silently skipped → transparent/black frames.
- AppStage (approach A): `AppHarness` mounts real `apps/app` views over ConnectorKit localnet + a pre-seeded, never-refetching react-query cache + MemoryRouter + `MotionConfig reducedMotion=always`; `makeDispute` display fixtures typed via `@useaccord/sdk`.
- Tests (TDD): sync scanner/renderer manifest contract (6 tests) + AppHarness renders the real DisputeList from seeded data in jsdom (1 test). All green.
- Verified end-to-end with system chromium (`--browser-executable /usr/bin/chromium`): compositions listed, stills render brand-exact pixels (ink #0a0e14, amber #f0a830, card #11161d), 90-frame mp4 encode succeeded, `new` scaffold round-trip verified.
- Docs: `apps/remotion/README.md` (agent manual), AGENTS.md layout+parts entries, .gitignore rules.
